# console打印

## console.table

可视化复杂的对象和数组

```js
const myData = [
  { name: "程序员Sunday", age: 30 },
  { name: "Sunday", age: 25 }
];
console.table(myData);
```

## console.trace

明确函数的调用逻辑关系

```js
function fn() {
  function test() {
    console.trace("这是一个利用trace的测试打印"); 
  }
  test();
}
fn();
```

## console.time && console.timeEnd

记录代码的执行耗时

```js
console.time('js 耗时')
const vNodes = []
for (let i = 0; i < 10000; i++) {
  const vNode = {
    type: 'div'
  }
  vNodes.push(vNode)
}
console.timeEnd('js 耗时')
```

## console.assert

断言为假，它抛出一个你指定的错误

```js
const myArray = []
console.assert(myArray.length > 0, "myArray 是空的!");
```
